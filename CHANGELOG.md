# Changelog

## v1.1.0 — 2026-10-04

### Веб-панель
- Панель теперь устанавливается и в LITE-версии: порт по умолчанию **8099**, если занят — автоматически подбирается свободный; порт можно менять в любой момент (пункт 16/17 меню)
- **Исправлено:** не сохранялись настройки через веб (прокси, .env) — ошибка распаковки в `write_env`
- **Исправлено:** `Failed to add match '|': Invalid argument` на дашборде панели
- Подсказки, когда действию нужны права root (в LITE панель работает от пользователя)

### Бот
- Кнопочное меню: 📝 Заметка, 🔍 Поиск, ⏰ Напомнить, 📋 Список, 🏷 Теги, 📤 Экспорт
- Новые команды: `/search` (полнотекстовый, с морфологией), `/tags`, `/export` (Markdown + JSON)
- Напоминания: `/remind` без даты → выбор времени кнопками (30 мин / 1 ч / 3 ч / сегодня 21:00 / завтра 09:00 / через неделю) или текстом
- Поддержка прокси для Telegram API (`PROXY_URL`: http/socks5)
- Официальное меню команд Telegram (`set_my_commands`)

### Сеть и часовой пояс
- Фикс доступа к Telegram: автоподбор рабочего IP, пин в `/etc/hosts` (провайдеры часто блокируют часть IP Telegram)
- Часовой пояс по умолчанию **Europe/Samara (UTC+4)**: в установщике (контейнер), в панели и в меню LITE (пункт 8) — влияет на напоминания

## v1.0.0 — 2026-10-03
