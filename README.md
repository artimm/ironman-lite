# IronMan Lite — Telegram-бот для заметок с веб-панелью

Установщик **ironmanlite.sh** разворачивает на Ubuntu **без Docker и контейнеров**:

- 🤖 **Telegram-бот заметок** — текст, фото, документы, голосовые; теги `#тег`; полнотекстовый поиск; напоминания на естественном русском («завтра в 15:00», «через 30 секунд») с выбором времени кнопками; экспорт в Markdown + JSON; кнопочное меню
- 🖥 **Веб-панель управления** — статус, логи, настройки, диагностика сети прямо из браузера

Всё ставится в `~/ironman`, автозапуск — через `systemd --user`.

---

## Установка

**Требования:** Ubuntu 20.04+ (или другой Linux с systemd), интернет. Root не обязателен — `sudo` нужен один раз (фикс `/etc/hosts`, linger).

**Одной командой:**

```bash
curl -fsSL https://raw.githubusercontent.com/artimm/ironman-lite/main/ironmanlite.sh -o ironmanlite.sh && bash ironmanlite.sh
```

**Дальше в меню установщика:**

1. Пункт **1** — «Установить всё» (бот + веб-панель + служба)
2. Пункт **5** — вставить токен бота

**Где взять токен:** Telegram → **@BotFather** → `/newbot` → придумайте имя и username → скопируйте токен вида `1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr4K-4s`.

Готово: напишите боту `/start` — придёт приветствие и кнопки меню. Установщик покажет адрес панели и пароль.

---

## Веб-панель

Открывается по адресу **`http://IP-машины:8099`** (порт по умолчанию — 8099; **если он занят, установщик сам подберёт свободный** и покажет итоговый адрес).

Вход — по паролю (генерируется при установке, показывается в итоговой сводке и хранится в `~/ironman/.panel-password`).

**Умеет:**

| Раздел | Возможности |
|---|---|
| Статус | Служба бота, рестарты, память, размер заметок, под каким именем бот опрашивает Telegram, доступ к Telegram API |
| Логи | Журнал бота (journalctl) прямо в браузере |
| Настройки | Токен, прокси, режим polling/webhook, ключи — редактирование .env без терминала |
| Сеть | Диагностика и «фикс Telegram» (подбор рабочего IP), смена DNS, прокси, часовой пояс |

Кнопки панели: перезапуск бота, фикс Telegram, смена DNS/прокси/часового пояса, смена пароля панели.

⚠️ Панель работает по **HTTP без шифрования** — используйте только в доверенной (домашней) сети, наружу не выставляйте. В LITE-версии панель работает от вашего пользователя: действия, требующие root (закрепление IP в `/etc/hosts`, смена DNS системы), панель подскажет сделать через меню `ironmanlite.sh`.

## Кнопки бота

После `/start` внизу экрана появляются кнопки — команды вводить не обязательно:

| Кнопка | Что делает |
|---|---|
| 📝 Заметка | Подсказка: просто напишите сообщение — это заметка |
| 🔍 Поиск | Нажали → написали слово → результаты поиска |
| ⏰ Напомнить | Нажали → написали текст («позвонить маме») → выбрали время кнопками |
| 📋 Список | Список заметок с кнопками (открыть, ✏️ редактировать, 🗑 удалить) |
| 🏷 Теги | Все теги; тап по тегу → заметки с ним |
| 📤 Экспорт | Присылает заметки файлами: Markdown + JSON-бэкап |

Примеры команд (если удобнее так): `/remind завтра в 15:00 позвонить врачу`, `/remind позвонить` (выбор времени кнопками), `/search молоко`, `/tags`, `/list`, `/export`, `/edit <заголовок>`, `/cancel`.

Теги — слова вида `#тег` прямо в тексте заметки: `купить молоко #покупки #дом`. Времена понимают секунды: «5 сек», «через 90 секунд», «через 1 час 30 минут».

## Управление вручную

```bash
systemctl --user status ironman          # статус бота
systemctl --user restart ironman         # перезапуск бота
systemctl --user status ironman-panel    # статус панели
journalctl --user -u ironman -f          # логи бота в реальном времени
```

Данные: `~/ironman/data/` (база SQLite + вложения).
Токен: `~/ironman/.env` (права 600). Пароль панели: `~/ironman/.panel-password`.
Конфиг установщика: `~/.ironmanlite-config`.

## Если бот молчит

1. Пункт **10** — статус: служба должна быть `active`, «Telegram: доступен».
2. Пункт **13** — логи. Если видны `TelegramNetworkError` / таймауты — провайдер блокирует Telegram.
3. Пункт **3** — диагностика: покажет, какие IP Telegram доступны.
4. Пункт **4** — «Фикс Telegram»: подберёт рабочий IP и пропишет его в `/etc/hosts` (нужен sudo), бот перезапустится. То же самое есть кнопкой в веб-панели.
5. Если блокируется всё — пункт **7**: укажите прокси (`socks5://user:pass@host:port` или `http://...`).

## Частые вопросы

**Автозапуск после перезагрузки?** Включён (systemd user + linger). Проверить: `systemctl --user status ironman`.

**Порт 8099 занят?** Установщик сам найдёт свободный и покажет его. Сменить вручную — пункт **17**.

**systemd недоступен (WSL, минимальный образ)?** Установщик это определит — запускайте пунктом **2** (бот работает в терминале, останов по Ctrl+C), логи в `~/ironman/data/bot.log`.

**Как перенести заметки на другую машину?** Пункт **15** — бэкап; на новой машине после установки распакуйте архив в `~/ironman/`: `tar -xzf ironman-lite-backup-*.tgz -C ~/ironman` и перезапустите службу.

**Как обновить бота и панель?** Пункт **9** — заменит код, заметки не тронет.

**Как удалить?** Пункт **18** — остановит службы и удалит `~/ironman` (спросит подтверждение).
