# IronMan Lite — Telegram-бот для заметок

Установщик **ironmanlite.sh** разворачивает Telegram-бота для ведения заметок **напрямую в Ubuntu** — без Docker и контейнеров. Файлы ставятся в `~/ironman`, автозапуск — через `systemd --user`.

Возможности бота: заметки (текст, фото, документы, голосовые), теги `#тег`, полнотекстовый поиск, напоминания на естественном русском («завтра в 15:00», «через 30 минут») с выбором времени кнопками, экспорт в Markdown + JSON, кнопочное меню.

---

## Установка

**Требования:** Ubuntu 20.04+ (или другой Linux с systemd), интернет. Root не обязателен — `sudo` нужен один раз (фикс `/etc/hosts`, linger).

**Одной командой:**

```bash
curl -fsSL https://raw.githubusercontent.com/artimm/ironman-lite/main/ironmanlite.sh -o ironmanlite.sh && bash ironmanlite.sh
```

**Дальше в меню установщика:**

1. Пункт **1** — «Установить всё» (файлы → `~/ironman`, venv, служба)
2. Пункт **5** — вставить токен бота

**Где взять токен:** Telegram → **@BotFather** → `/newbot` → придумайте имя и username → скопируйте токен вида `1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr4K-4s`.

Готово: напишите боту `/start` — придёт приветствие и кнопки меню.

## Кнопки бота

После `/start` внизу экрана появляются кнопки — команды вводить не обязательно:

| Кнопка | Что делает |
|---|---|
| 📝 Заметка | Подсказка: просто напишите сообщение — это заметка |
| 🔍 Поиск | Нажали → написали слово → результаты поиска |
| ⏰ Напомнить | Нажали → написали текст («позвонить маме») → выбрали время кнопками |
| 📋 Список | Список заметок с кнопками (открыть, ✏️ редактировать, 🗑 удалить) |
| 🏷 Теги | Все теги; тап по тегу → заметки с ним |
| 📤 Экспорт | Присылает заметки файлами: Markdown + JSON-бэкап |

Примеры команд (если удобнее так): `/remind завтра в 15:00 позвонить врачу`, `/search молоко`, `/tags`, `/list`, `/export`, `/edit <заголовок>`, `/cancel`.

Теги — слова вида `#тег` прямо в тексте заметки: `купить молоко #покупки #дом`.

## Управление вручную

```bash
systemctl --user status ironman          # статус
systemctl --user restart ironman         # перезапуск
journalctl --user -u ironman -f          # логи в реальном времени
```

Данные: `~/ironman/data/` (база SQLite + вложения).
Токен: `~/ironman/.env` (права 600). Конфиг установщика: `~/.ironmanlite-config`.

---

## Если бот молчит

1. Пункт **9** — статус: служба должна быть `active`, «Telegram: доступен».
2. Пункт **12** — логи. Если видны `TelegramNetworkError` / таймауты — провайдер блокирует Telegram.
3. Пункт **3** — диагностика: покажет, какие IP Telegram доступны.
4. Пункт **4** — «Фикс Telegram»: подберёт рабочий IP и пропишет его в `/etc/hosts` (нужен sudo), бот перезапустится.
5. Если блокируется всё — пункт **7**: укажите прокси (`socks5://user:pass@host:port` или `http://...`).

## Частые вопросы

**Автозапуск после перезагрузки?** Включён (systemd user + linger). Проверить: `systemctl --user status ironman`.

**systemd недоступен (WSL, минимальный образ)?** Установщик это определит — запускайте пунктом **2** (бот работает в терминале, останов по Ctrl+C), логи в `~/ironman/data/bot.log`.

**Как перенести заметки на другую машину?** Пункт **14** — бэкап; на новой машине после установки распакуйте архив в `~/ironman/`: `tar -xzf ironman-lite-backup-*.tgz -C ~/ironman` и перезапустите службу.

**Как обновить бота?** Пункт **8** — заменит код, заметки не тронет.

**Как удалить?** Пункт **15** — остановит службу и удалит `~/ironman` (спросит подтверждение).
